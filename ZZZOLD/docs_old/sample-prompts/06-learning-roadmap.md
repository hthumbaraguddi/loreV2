# Prompt: Learning Roadmap

**Output type:** HTML  
**Best for:** Testing timeline layouts, milestone cards, skill badges, progress bars

---

## Prompt

```
Generate a styled HTML learning roadmap for becoming a full-stack developer in 6 months (starting March 2026).

Structure:
- Header: "Full-Stack Developer Roadmap · 6 Months" with a progress bar showing 0% complete
- 6 monthly phases, each as a card with:
  - Phase number + month name
  - Phase title (e.g. "Month 1: HTML, CSS & Git Foundations")
  - 4-5 skill badges (pill-shaped, colored by category: blue=frontend, green=backend, purple=tools)
  - A "Key Project" callout box
  - Estimated hours per week
- A "Tech Stack" summary section at the bottom showing all technologies as a tag cloud
- Footer: "Track your progress in Lore"

Use inline CSS only. Modern card-based design with:
- Soft shadows on cards
- Left colored border per phase (gradient from blue → purple → green as phases progress)
- Clean sans-serif typography
- Responsive-friendly layout
```

---

## What to expect in Lore

- Rich timeline layout with 6 phase cards
- Colored skill badge pills
- Progress bar in header
- Tag cloud at the bottom
- Auto-detected as **HTML**
