Documents You Need to Generate
Five documents, in this order:

Product Requirements Document (PRD) — what the app does, user stories, feature list, acceptance criteria
Design System Specification — colours, tokens, typography, component library, dark mode rules
Technical Architecture Document — Angular module structure, state management, routing, API contracts
Component Specification Document — every UI component mapped to its inputs, outputs, state, and Angular selector
Agent Prompt Playbook — the actual prompts you paste into Kiro / Copilot / Claude Code per feature
