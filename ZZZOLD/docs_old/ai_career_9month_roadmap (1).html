AI Career — 9-Month Roadmap

A structured learning path for experienced software engineers transitioning into AI/LLM engineering

Phase 1 Foundations — Math & Python Months 1 – 2 ▾
Mentor tip: Don't try to finish all math before coding. Learn linear algebra and basic stats now. Calculus intuition is enough — you don't need to hand-derive gradients.
What to learn
Linear algebra — vectors, matrices, dot products, eigenvectors (intuition, not proofs)
Statistics & probability — distributions, Bayes, hypothesis testing
Calculus — derivatives, chain rule, gradient intuition only
Python for data — NumPy, Pandas, Matplotlib, Jupyter
Python advanced — decorators, generators, OOP, typing
Best resources
3Blue1Brown — Essence of Linear Algebra
3Blue1Brown — Essence of Calculus
StatQuest with Josh Starmer (YouTube)
fast.ai Practical Deep Learning (Ch. 1-2)
Real Python
🎯 Milestone: Build a Jupyter notebook that loads a CSV dataset, cleans it, runs descriptive stats, and plots 3 meaningful visualizations.
Phase 2 Classical Machine Learning Months 3 – 4 ▾
Mentor tip: Don't skip classical ML to jump straight to deep learning. Interviewers ask about it. More importantly, many real-world problems are best solved with XGBoost, not a transformer.
What to learn
Supervised learning — regression, classification, decision trees, random forests, XGBoost
Unsupervised — clustering, PCA, dimensionality reduction
Model evaluation — train/val/test splits, cross-validation, ROC, precision/recall
scikit-learn end to end — pipelines, preprocessing, hyperparameter tuning
MLflow basics — experiment tracking
Best resources
Andrew Ng's ML Specialization (Coursera)
Kaggle Learn
Kaggle Competitions
StatQuest ML playlist
🎯 Milestone: Complete 2 Kaggle competitions. Place in top 50% on at least one. Push code to GitHub.
Phase 3 Deep Learning & How LLMs Work Months 5 – 6 ▾
Mentor tip: Karpathy's "Neural Networks: Zero to Hero" series is genuinely the best resource on the internet for understanding LLMs from first principles. Watch it. Code along. Don't just watch — type every line.
What to learn
Neural networks from scratch — forward pass, backprop, gradient descent
CNNs, RNNs — understand the progression to transformers
Transformers & attention — the "Attention is All You Need" paper (read alongside Karpathy)
PyTorch fundamentals — tensors, autograd, training loops
Hugging Face ecosystem — models, tokenizers, datasets, pipelines

🎯 Milestone: Build a character-level language model from scratch (following Karpathy). Fine-tune a Hugging Face model on a custom classification task.
Phase 4 Building LLM Applications + Fine-tuning Months 7 – 8 ▾
Mentor tip: This phase is your highest-leverage career investment right now. The job market is flooded with people who understand ML theory — it's starved for engineers who can ship RAG systems, agents, and LLM-powered products to production.
What to learn
Prompt engineering — system prompts, few-shot, chain-of-thought, structured outputs
RAG (Retrieval Augmented Generation) — vector databases, embeddings, chunking strategies
LLM Agents & tool use — function calling, ReAct, planning patterns
Fine-tuning — LoRA, QLoRA with Unsloth/PEFT (parameter-efficient methods)
Production deployment — FastAPI, Docker, LLM observability (LangSmith/Langfuse)
Evaluation — LLM-as-judge, RAGAS, building eval pipelines

Phase 5 Portfolio, Job Search & Interview Prep Month 9 ▾
Mentor tip: A working GitHub project beats a certificate every time. Two strong end-to-end projects will open more doors than 10 course completions. Start applying from month 7 — don't wait until you feel "ready".
Actions
Polish 2–3 portfolio projects with clean READMEs and demos
Write 2–3 blog posts on what you built (Medium, Substack, or LinkedIn)
Update LinkedIn — "AI/ML Engineer" or "LLM Engineer" in headline
Mock interviews — LeetCode (medium), ML system design, LLM architecture questions
Target roles: LLM Engineer, ML Engineer, AI Product Engineer, AI Consultant
Job search tactics
LinkedIn — AI Engineer jobs
Wellfound / AngelList
fast.ai Deep Learning for Coders (free book)
Contribute to 1 open source AI project
Attend local AI/ML meetups
🎯 Target: 3 portfolio projects on GitHub, 2 blog posts published, 10+ applications sent, 3+ interviews scheduled.
