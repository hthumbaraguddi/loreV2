# Prompt: Financial Report Card

**Output type:** HTML  
**Best for:** Testing KPI cards, color-coded indicators, tables in HTML

---

## Prompt

```
Generate a styled HTML quarterly report card for a fictional SaaS company called "Nexus Analytics" — Q1 2026.

Include:
- Header with company name, quarter, and a subtle gradient background
- KPI row with 4 metric cards:
  - MRR: $2.4M (↑ 18% QoQ) — green indicator
  - Churn Rate: 3.2% (↑ 0.4%) — red indicator  
  - NPS Score: 67 (↑ 5 pts) — green indicator
  - Active Users: 14,200 (↑ 22%) — green indicator
- Revenue Breakdown table: Product | Q4 2025 | Q1 2026 | Change
  - Core Platform: $1.8M → $2.1M (+16%)
  - Add-ons: $180K → $240K (+33%)
  - Professional Services: $60K → $60K (flat)
- Key Wins section: 3 bullet points
- Key Risks section: 2 bullet points with red left border
- Clean footer with "Prepared by Finance Team · March 2026"

Use inline CSS only. Professional, clean design — think Notion meets a finance dashboard.
```

---

## What to expect in Lore

- Color-coded KPI cards (green/red)
- Structured data table
- Risk section with visual distinction
- Auto-detected as **HTML**
