# Prompt: Tech Research Summary

**Output type:** Markdown  
**Best for:** Testing headings, tables, code blocks, blockquotes

---

## Prompt

```
Write a research summary on the current state of WebAssembly (WASM) in 2026.

Structure it as follows:
- # Title heading
- ## Overview section (2-3 paragraphs)
- ## Key Use Cases (bullet list with bold labels)
- ## Pros vs Cons (markdown table with 3 rows each)
- ## Code Example — show a minimal WASM module in a fenced code block
- ## Key Takeaway as a blockquote

Keep it informative and realistic. Use proper markdown formatting throughout.
```

---

## What to expect in Lore

- Large `h1`/`h2` headings with hierarchy
- Styled comparison table
- Syntax-highlighted code block
- Accent-colored blockquote at the end
- Auto-detected as **Markdown**
