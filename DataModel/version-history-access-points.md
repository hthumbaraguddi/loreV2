# Version History - Access Points

## How to Access Version History

There are now **TWO ways** to access version history for a note:

---

## 1. From Sidebar (Right-Click Menu)

**Steps:**
1. Find the note in the sidebar
2. **Right-click** on the note
3. Select **"Version History"** from context menu
4. Version history modal opens

**Best for:**
- Quick access from sidebar
- When browsing notes
- When note is not currently open

---

## 2. From Editor (History Button)

**Steps:**
1. Open a note in the editor
2. Look at **top-right corner** of the note pane
3. Click the **History icon** (clock/history symbol) ⏱️
4. Version history modal opens

**Best for:**
- While actively editing
- Quick access without leaving editor
- Checking recent changes

---

## Version History Features

Once opened, you can:

### Timeline Tab
- View all versions chronologically
- See session versions (automatic)
- See manual snapshots
- See milestones
- Create new snapshots/milestones
- Restore to any version
- Delete versions

### Compare Tab
- Select two versions
- See what changed between them
- View detailed differences

### Analytics Tab
- Total versions
- Change statistics
- Most active day
- Session duration averages
- Version breakdown by type

---

## Quick Actions

### Create Manual Snapshot
1. Open version history
2. Click **"📸 Quick Snapshot"**
3. Done!

### Create Milestone
1. Open version history
2. Click **"⭐ Create Milestone"**
3. Enter label (e.g., "Final Draft")
4. Add description (optional)
5. Click **"Create"**

### Restore Version
1. Open version history
2. Select a version from timeline
3. Click **"↺ Restore"**
4. Review preview
5. Click **"✓ Confirm Restore"**

---

## Automatic Versioning

**You don't need to do anything!**

Versions are created automatically when:
- ✅ You finish editing a note (session ends)
- ✅ You switch to a different note
- ✅ You close the editor
- ✅ You close the browser

**Smart detection:**
- Only creates versions for significant changes
- Skips trivial edits (< 50 characters)
- Respects minimum time between versions (5 min)

---

## Tips

💡 **Use the History button while editing** - Quick access without leaving your workflow

💡 **Right-click from sidebar** - Access history for any note, even if not open

💡 **Check console logs** - See when sessions start/end (F12 → Console)

💡 **Create milestones for important moments** - They're never auto-deleted

💡 **Compare versions to see your progress** - Great for tracking how ideas evolved
