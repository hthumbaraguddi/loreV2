# Prompt: Styled HTML Newsletter

**Output type:** HTML  
**Best for:** Testing full HTML rendering — gradients, cards, badges, typography

---

## Prompt

```
Generate a beautifully styled HTML email newsletter called "Dev Digest — March 2026".

Cover these 3 frontend trends:
1. AI-native UI components (React + LLM integration)
2. CSS Houdini going mainstream
3. Edge-first rendering replacing traditional SSR

Requirements:
- Full HTML document with <!DOCTYPE html> and inline CSS only (no external stylesheets)
- Dark gradient header with newsletter name and issue number
- Each trend as a styled card with: colored top border, icon area, title, 2-paragraph description, and a "Read more →" link
- A "Tool of the Week" section with a highlighted box
- A minimal footer with unsubscribe link
- Use a clean typographic hierarchy: large serif title, sans-serif body
- Color palette: deep navy background for header, white cards, purple/blue accents

Make it visually polished — the kind of newsletter a developer would actually enjoy reading.
```

---

## What to expect in Lore

- Full styled HTML rendered inside the note card
- Original fonts, colors, gradients preserved
- Auto-detected as **HTML**
- Note title extracted from `<title>` tag
