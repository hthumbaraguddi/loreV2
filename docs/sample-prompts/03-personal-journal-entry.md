# Prompt: Personal Journal Entry

**Output type:** Markdown  
**Best for:** Testing italic text, nested lists, blockquotes, mixed formatting

---

## Prompt

```
Write a reflective journal entry about spending a week learning Rust as a JavaScript developer.

Structure:
- # Journal — [a date in March 2026]
- ## What I Learned Today (bullet list, mix of plain and **bold** items)
- ## Challenges (numbered list of 3 struggles, each with a sub-bullet explaining why)
- ## A Moment That Clicked (short paragraph with *italic* emphasis)
- ## Tomorrow's Goals (checklist style: `- [ ] item`)
- End with an inspiring quote as a > blockquote

Write in first person, conversational tone. Use markdown formatting throughout.
```

---

## What to expect in Lore

- Personal, readable tone with rich formatting
- Nested bullet lists
- Checkbox-style task list
- Italic and bold inline emphasis
- Auto-detected as **Markdown**
